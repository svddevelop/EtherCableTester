Прошивка тестера Ethernet-кабеля в этой папке уже собрана по `Description.md` на фреймворке Stefan Wagner. Я поправил то, из-за чего она не собиралась и не записала бы настройки в Flash CH32V003.

Оба блока одинаковые: CH32V003A4M6, один конец кабеля в RJ45, энкодер с кнопкой и SSD1306 128×64 по программному I2C. SWIO (PD1) оставлен только под программатор.

Разводка SOP-16:

| Сигнал | Пин | Ножка |
|---|---|---|
| RJ45 1…5 | PC0, PC1, PC2, PC3, PC4 | 16, 1, 2, 3, 4 |
| RJ45 6…8 | PC6, PC7, PD4 | 5, 6, 8 |
| Энкодер A, B, кнопка | PD5, PD6, PD7 | 9, 10, 11 |
| I2C SDA, SCL | PA1, PA2 | 12, 13 |

Классы:

- `CPins` — на каждый контакт режим 0, 1 или ШИМ 1 кГц. В режиме REC все линии переводятся в вход.
- `CEncoder` — поворот влево/вправо по прерыванию EXTI и короткое/длинное нажатие.
- `CDisplay` — три строки по 8 позиций: номера 1…8, символ режима (перевёрнутая Т, `+`, синус), пункт меню.
- `CFlash` — `save`/`load` структуры по ссылке в последнюю страницу Flash (64 байта, `0x08003FC0`), с magic и CRC16.

Управление: поворот выбирает контакт или пункт меню, короткое нажатие меняет режим пина (0 → 1 → ШИМ) либо запускает REC / SEND / SAVE, длинное открывает меню и выходит из режима. При старте `g_cfg` читается из Flash.

Что изменено по факту чипа: команды SSD1306 шли с лишним байтом `0x00`, а установка окна столбцов вызывалась с тремя аргументами и не компилировалась. Запись Flash переведена на страницу 64 байта (`PAGE_ER` / `PAGE_PG`); линкер больше не кладёт код в эту страницу. Для C++ в проект добавлен include-путь `User`. Собрать здесь не удалось: `riscv-none-embed-g++` в PATH нет, сборка остаётся в MounRiver.
